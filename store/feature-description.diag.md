# GpuiTizen Diag

A template for Seller Office's feature description file; complete the bracketed parts before submitting.

## What the app does

Shows what the TV offers a GPUI app: the EGL and GL ES details, the CPU, the display and launch timings, on one
screen. Developers use it to check a TV before installing apps built on dXn.GpuiTizen.

## Screens and controls

- One screen, the report. Up and Down scroll it; Back closes the app.
- Everything is reachable with the four directions, OK and Back.

## Privileges

- `http://tizen.org/privilege/internet`: [the report is pulled over the development port with `sdb forward`; no data
  leaves the TV otherwise].

## Content and data

No account, no purchases, no personal data. [Contact for review questions.]
