# GpuiTizen Counter

A template for Seller Office's feature description file; complete the bracketed parts before submitting.

## What the app does

A counter: a number and two buttons that raise and lower it. It shows a GPUI app running on the TV.

## Screens and controls

- One screen. Left and Right move between the buttons, OK presses one, Back closes the app.
- Everything is reachable with the four directions, OK and Back.
