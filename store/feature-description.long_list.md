A template for Seller Office's feature description file; complete the bracketed parts before submitting.

## What the app does

A list of 1,000 rows with a filter field above it. It shows scrolling and text input in a GPUI app on the TV.

## Screens and controls

- One screen. Up and Down move the selection; Up from the first row enters the filter field, where the TV's
  on-screen keyboard types; Down, OK or Back leave the field; Back closes the app.
- Everything is reachable with the four directions, OK and Back.
